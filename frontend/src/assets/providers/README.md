# 模型品牌 SVG

来源：LobeHub lobe-icons，@lobehub/icons-static-svg 1.95.0（MIT）。
源码：https://github.com/lobehub/lobe-icons
版本包：https://registry.npmjs.org/@lobehub/icons-static-svg/-/icons-static-svg-1.95.0.tgz

GLM 使用 zai.svg 的 Z.ai 标志，不使用历史 ChatGLM 大象或旧智谱点阵图标；Kimi 使用 kimi-color.svg 的 K 标志和蓝色圆点，不使用 Moonshot 月球标志。Kimi 的白色前景改为 currentColor 适配明暗主题，路径和蓝色圆点不变。其它文件对应同名 color.svg，OpenAI 使用单色版。

官方品牌核对：https://chat.z.ai/ 、https://www.kimi.com/ 、https://github.com/zai-org/GLM-5 。品牌商标归各自所有者，图标仅用于模型和供应商标识。
