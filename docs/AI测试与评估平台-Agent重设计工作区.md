## 待重新确定的三项设计

1. 模型调用层：统一模型供应商、同步/流式协议、超时、重试、结构化输出和脱敏边界；
2. Harness：定义输入输出契约、工具执行边界、事件模型、取消与错误归一化；
3. Agent 范式：确定单轮调用、ReAct、计划/反思等能力是否需要，以及它们与 Harness 的依赖关系。

在三项设计完成并评审前，不恢复旧 Agent 代码，不新增并行实现，不新增数据库迁移。
