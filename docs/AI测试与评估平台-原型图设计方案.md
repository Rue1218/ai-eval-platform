### 1.2 全局状态

| 状态 | 表现 |
| --- | --- |
| 未登录 | 任何受保护路由 → `/login` |
| 无权限路由 | 守卫回 `/tasks`（只读）或 `/agent`；Toast `UNAUTHORIZED`；不整页 403 |

## 4. `/agent` 智能体（F-AGT-01～06、09）— 核心页

### 4.2 区块规格

| 区块 | 内容 | 数据来源 |
| --- | --- | --- |
| SessionList | 新建按钮；项=自动标题（首句截断）+ 相对时间 + 非终态 KindTag 小点 | `GET /api/sessions`；切换后 `GET /api/sessions/{id}/messages` 回放 + WS 补发 |
| ChatHead | 会话标题；只读「Agent · {模型名}」（来自 settings.agent_profile_id 对应档）；生成中 pill | `GET /api/admin/settings` + `GET /api/profiles` |
| ChatStream | UserBubble / AssistantText / ThoughtCard / ToolCard / ConfirmCard / ReportCard / ErrorStrip | WS 事件 |
| ProgressDock | KindTag + `done/total` 或 `percent` + message + 取消按钮 | WS `progress`；压测曲线走 `GET /api/tasks/{id}/stress-series` |
| Composer | textarea ≥44px；附件钮 36×36；右侧只读模型名 + 发送 40×40 圆钮 | 附件先 `POST /api/files` |

### 4.3 消息组件规格

**UserBubble**：右对齐；`--accent-ai` 底白字；圆角 20px 右下 6px；15px；附件芯片挂气泡下（文件名 + 大小）。

**AssistantText**：左对齐；16px / 行高 1.9；支持 Markdown（报告摘要）。

**ThoughtCard**（event=`thought`）：标题「思考」；流式追加；结束 800ms 后收起 `opacity:.55`；用户不可编辑。

**ToolCard**（`tool_call`→`tool_result`）：标题用中文名（列出协议档 / 列出数据集 / 列出知识库 / 查询任务 / 读取报告 / 创建任务 / 取消任务 / 确认用例入库）；**界面不展示 MCP 函数名**（规范 5.2；线框中的中文即最终标题）；pending 旋转「调用中」→ done 绿 / 失败红徽章；默认折叠，展开见 arguments / data；失败 error 同时进入 Agent 下一轮上下文。

**ConfirmCard**（event=`confirm`）：对话流内，**不是 Modal**；宽随对话列（≤760px）；圆角 14px；上滑入场。字段用 Naive 控件，与抽屉同一 schema：

| kind | 卡标题 | 可见字段 |
| --- | --- | --- |
| benchmark | 确认基准评测 | profile_ids 多选 1–5、dataset_id 下拉（名称 vN · 行数）、run 折叠、with_stress 开关、stress（env/qps/duration_s/sla_p99_ms） |
| rag | 确认 RAG 评测 | kb_id + gold_qa_id 双下拉、rag_mode 多选 1–4 默认 hybrid、外部 Chat 时 profile_ids 单选「RAG 服务」档、run、with_stress、stress |
| testcase | 确认生成用例 | case_source（file_id 芯片或粘贴文本域） |
| stress | 确认压测 | 一般不手选；展示继承自父任务的目标与 stress 段 |

- 主按钮「确认并开始」黑底白字（深色反相）；次按钮「取消」→ `confirm_ack {ok:false}`。  
- 未 ack 前可改字段（作为 `patch`）；确认后整卡变只读灰底。  
- 校验失败红字留卡内（`VALIDATION` / `WHITELIST` / `NEED_APPROVAL` / `CONCURRENCY` / `BUDGET_EXCEEDED`），不 Toast。  
- 会话占槽（含压测子任务）：主按钮禁用 + 说明「当前会话已有进行中的任务」。  
- `prod` + 压测：卡上只读展示会签人列表。

**ReportCard**（event=`report`）：3–4 个 `.num` KPI + 「查看报告」→ `/reports/:id`；M4 增加「在对话中解读」（带 `report_id` 回 `/agent`，不重跑）。

**ErrorStrip**（event=`error`）：对话内红条（用户可读 message）+ Toast；`INTERNAL` 不展示堆栈。

**ProgressDock**（event=`progress`）：

| 任务态 | 内容 | 操作 |
| --- | --- | --- |
| 评测 running | kind 徽章 + done/total + message | 「取消」→ Dialog「当前样本结束后停止」→ WS `cancel_task` |
| 压测 running | 徽章 + 迷你 QPS/RT/错误率（轮询 stress-series） | 「立即停止」→ Dialog「立即停止发压」→ WS `cancel_task` |
| awaiting_case_confirm | 文案 + 72h 倒计时 | 「去确认」→ `/cases` |
| prod 压测 queued | 「等待会签」 | 无可点操作（会签人另有入口） |

### 4.4 空态与快捷芯片

空会话：一句「说明要评什么（模型 / RAG / 生成用例），我会澄清后给你确认卡。」+ 最多 4 个芯片：「生成用例」「基准评测」「RAG 评测」「先评后压」。点击只预填一句话，仍走澄清 + 确认卡。

### 4.5 状态矩阵

| 状态 | 表现 |
| --- | --- |
| 无协议档 | Agent 澄清后告知「请管理员先配置协议档」；确认卡不出 |
| 无数据集 | 确认卡 dataset 下拉空态「暂无数据集，请先到数据集页上传」 |
| 占槽 | 仍可聊天澄清；会入队的确认卡按钮禁用 |
| 断线 | ChatHead 下 info 条；30s 心跳（传输层 ping/pong，应用层仅服务端 `pong`）；重连带 `session_id` + `last_event_id` 补齐 |
| 只读 | 路由不可达（侧栏无入口） |
| 附件超限 | 选择时即 Toast「单文件不超过 20MB」；类型白名单见 API §1.4 |

### 4.6 时序（原型走查用）

```
user_message → thought → tool_call/tool_result（可多轮）
  → confirm →（用户）confirm_ack
      ok=false → 卡标已取消
      ok=true  → queued → ProgressDock 出现 → progress… → report / error
  → with_stress 且质量 succeeded → 压测子任务自动占槽（prod 先会签）
```

### 5.1 线框

```
┌──────────────────────────────────────────────────────────────────┐

│ ┌────┬──────────┬──────────┬─────────┬──────────┬──────┬───────┐ │

│ ├────┼──────────┼──────────┼─────────┼──────────┼──────┼───────┤ │
│ │a1f │[benchmk] │● running │ 40/100  │smoke v3  │alice │2分钟前│ │
│ │b2e │[rag]     │✓succeeded│ —       │default库 │bob   │1小时前│ │

```

| 列 / 元素 | 规格 | 数据来源 |
| --- | --- | --- |
| 筛选 | 状态（六态）、kind（四种） | `GET /api/tasks?status=&kind=` |
| 状态列 | StatusBadge；压测 queued 且 `NEED_APPROVAL` 时副文案「等待会签」 | 同上 |
| 关联列 | 数据集名 vN 或 KB 名；压测行显示「↳ 父 {id}」 | `parent_task_id` |
| 进度列 | running 显示 done/total；压测 running 附当前 QPS | `progress` + stress-series |
| 行操作 | 详情（DetailDrawer）、取消（Dialog，按 kind 分流文案）、复制为新任务（`POST .../rerun`）、查看报告（有 `report_id` 才显示） | 权限：只读全部隐藏 |

### 5.2 DetailDrawer（520px）

```
┌─ 任务详情 ────────────────────────────┐
│ [benchmark] ● running                 │
│ ID a1f… · 创建者 alice · 2 分钟前      │
│ ── 配置快照（只读 JSON 折叠）          │

│ ──────────────────────────────────────│
│ [查看报告]  [取消任务]  [复制为新任务]  │
└────────────────────────────────────────┘
```

数据来源：`GET /api/tasks/{id}`（config 快照 + events 时间线）。

### 5.3 状态矩阵

| 状态 | 表现 |
| --- | --- |
| 空 | EmptyState「暂无任务」+（工程师+）「去智能体下单」 |
| 加载 | 表格 skeleton |
| 失败 | ErrorStrip + 重试 |
| 只读 | 无写操作列；筛选与详情可看 |
| 取消中 | 按钮 loading；评测取消后状态可能短暂 running（当前样本结束后停） |

原型页面必须在走查时明确回答“这个数从哪里来”。`Web-Prototype` 顶栏显示数据模式：默认“实时 API”，`?data=mock` 时显示“示例 Mock”。没有这个标识的截图不能作为接口联调验收材料。

| 页面/区域 | 静态 UI | Mock（仅显式模式） | 实时数据/API | 失败时应该显示 |
| --- | --- | --- | --- | --- |
| 全局壳 | 导航、模块色、状态枚举、表头 | 无 | 当前用户 `/auth/me`（正式前端） | 未登录/加载错误，不伪造 admin |
| Agent | 消息卡/确认卡样式 | 示例会话、工具卡、确认卡 | sessions、profiles、datasets/KB、WS、tasks | 空会话或连接错误 |
| 调度/任务 | 图例、状态颜色、节点形状 | 演示节点/趋势可视素材 | overview/workers/tasks/events/config | 空节点、队列为空、请求错误 |

| 管理页 | 表格列、阈值范围、提示文案 | 示例协议档/白名单/成员 | profiles/settings/whitelist/users/audit | 空列表或权限/接口错误 |

### 17.1 原型交互验收顺序

1. 在 `?data=mock` 下只验布局、状态、表单交互；记录为“Mock 走查”。
2. 切回无参数的默认地址，确认顶栏为“实时 API”。
3. 为页面执行一次读、一次写、一次刷新回读；在浏览器 Network 保存证据。
4. 停止 API 或返回 500，确认页面显示错误/空态，且不出现任何示例任务、报告、用户或图表数值。
5. 只有第 2–4 步都通过，才记录为“API 已接入”。

### 17.2 现有原型的整改口径

- 示例业务实体统一归入 `MOCK_SEED`；页面缓存初始为空。
- `assets/api.js` 默认真实 fetch，保留 Cookie，显式处理 JSON、FormData 和 Blob；网络错误与非 2xx 不允许自动降级。
- 任务“复制为新任务”调用 `POST /api/tasks/{id}/rerun`，不在浏览器用固定协议档/数据集拼 TaskSpec。
- V1.0 未定义删除会话接口，原型不再展示或调用该操作。
- 趋势线、拓扑随机推进、示例报告、KB 投影和候选生成均仅在 `?data=mock` 保留；实时模式无对应接口时展示空态/说明，不把视觉样本当真实指标。
- KB 切块预览新增 `GET /api/kb/{id}/documents/{doc_id}/chunks`；数据集与用例 AI 接口只返回候选，采纳动作另行落库。
3. 会话回放用 `GET /api/sessions/{id}/messages`（含 events），避免刷新丢工具卡。  
4. 待补全入口在 `/datasets` 详情而非独立页面，路由不增。  
5. 通知开关放 `/admin/stress`（规范 5.9），不单开页面。
